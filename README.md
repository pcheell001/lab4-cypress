
# Лабораторна робота №4

## Тема
Стандарти та технології тестування вебзастосунків.

## Мета роботи
Ознайомлення з фреймворком Cypress.

## Використані технології
- JavaScript
- Node.js
- Cypress
- Visual Studio Code
- Git
- GitHub

## Завдання 1
Автоматизація математичної форми:
https://suninjuly.github.io/math.html

Реалізовано:
- відкриття вебсторінки;
- отримання значення x;
- обчислення математичної функції;
- введення результату;
- вибір checkbox та radiobutton;
- надсилання форми;
- перевірку результату.

## Завдання 2
Відповідно до уточнення викладача
замість недоступного demostore.website
обрано демонстраційний ресурс OpenCart:

https://demo.opencart.cn/

Перевірено:
- навігацію основними сторінками;
- реєстрацію тестового користувача;
- пошук товару;
- відображення порожнього кошика.

## Завдання 3
Створення GitHub-репозиторію з Cypress-тестами.

## Встановлення
npm install

## Запуск усіх тестів
npm test

## Графічний інтерфейс Cypress
npm run cy:open

## Структура тестів
- math.cy.js
- navigation.cy.js
- registration.cy.js
- features.cy.js

## Примітка
Результати тестів залежать від доступності
зовнішніх демонстраційних вебресурсів.
